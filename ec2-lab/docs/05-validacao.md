> [!TIP]
> **O que conferir nessa tela:**
> * **Estado da instância:** precisa estar *Executando* (running)
> * **Verificações de status:** precisam passar (ex.: *2/2 verificações aprovadas*). Uma checa a infraestrutura da AWS, a outra checa a própria instância
> * **IP público / DNS público:** é o endereço usado para acessar o site depois que o Security Group liberar a porta 80
